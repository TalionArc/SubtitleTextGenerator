# 영상·녹음 자막 텍스트 생성기

영상에서는 SRT 자막을, 녹음 파일에서는 TXT 녹취를 만들어 주는 Windows 프로그램입니다. 인식은 전부 내 PC의 NVIDIA GPU에서 이루어지며, 파일을 외부로 올리지 않습니다.

- 영상(MP4, MKV, MOV, AVI, WEBM, M4V, WMV, TS) → `영상이름.srt`
- 오디오(M4A, MP3, WAV, FLAC, AAC, OGG, OPUS, WMA, AIF, AIFF, MKA) → `오디오이름.txt`
- 폴더를 고르면 하위 폴더까지 찾아 목록으로 보여 주고, 고른 파일을 순서대로 처리합니다.
- `large-v3-turbo`로 빠르게 초안을 만든 뒤 신뢰도가 낮은 구간만 `large-v3`로 다시 인식합니다.

## 시작 전에 확인하세요

| 항목 | 내용 |
| --- | --- |
| 운영체제 | Windows 10 / 11 64비트 |
| 그래픽카드 | **NVIDIA GPU 필수.** CPU, AMD, Intel 그래픽으로는 동작하지 않습니다. |
| 저장 공간 | **설치 후 약 10GB**를 사용합니다. 다운로드는 약 5.7GB이고, 설치하는 동안 여유 공간이 12GB 이상 있어야 합니다. |
| 인터넷 | 첫 설치 때만 필요합니다. 이후 인식은 오프라인으로 됩니다. |
| 인식 언어 | **한국어 전용**입니다. 다른 언어 음성은 제대로 인식되지 않습니다. |

EXE 자체는 약 12MB이고, 나머지 용량은 처음 실행할 때 내려받는 인식 엔진과 모델입니다.

## 설치와 첫 실행

1. [Releases](https://github.com/TalionArc/SubtitleTextGenerator/releases/latest)에서 `SubtitleTextGenerator.exe`를 받습니다.
2. 용량이 넉넉한 드라이브의 **쓰기 가능한 폴더**에 둡니다. 예: `D:\SubtitleTextGenerator\`. `Program Files` 같은 보호 폴더는 피하세요.
3. 실행하면 설치 용량과 위치를 알려 주는 확인 창이 뜹니다. `예, 설치`를 누르면 엔진과 모델을 내려받습니다.
4. 하단에 `인식 환경 준비 완료`가 보이면 사용할 수 있습니다.

확인 창에서 `아니오`를 누르면 아무것도 설치하지 않습니다. 나중에 `용어집 / 설정` 탭의 `환경 검사 / 복구`로 설치할 수 있고, `다시 표시하지 않기`를 체크하고 `아니오`를 누르면 다음 실행부터 확인 창을 띄우지 않습니다.

다운로드는 중간에 끊겨도 다음 실행 때 이어받습니다.

## 사용법

1. `폴더 선택`으로 영상·녹음 파일이 있는 폴더를 고릅니다.
2. 처리할 파일의 `선택` 칸을 누르거나 `결과 없는 파일 모두 선택`을 누릅니다.
3. `선택 생성 (Turbo → 보정)`을 누릅니다. 한 번에 한 파일씩 순서대로 처리합니다.
4. 결과는 원본과 같은 폴더에 같은 이름으로 저장됩니다.

| 버튼 | 동작 |
| --- | --- |
| 선택 생성 (Turbo → 보정) | 기본 동작. 이미 결과가 있는 파일은 건너뜁니다. |
| 선택 재생성 | 기존 결과를 `.bak`으로 보관하고 다시 만듭니다. |
| 선택 전체 large-v3 | 파일 전체를 `large-v3`로 인식합니다. 느리지만 가장 정확합니다. |
| 중지 | 진행 중인 인식과 남은 대기열을 취소합니다. |

목록의 `메시지`가 길면 가로 스크롤로 끝까지 볼 수 있습니다. 행 위에 마우스를 잠시 올려 두면 전체 메시지가 말풍선으로 나오고, 행을 더블클릭하면 복사할 수 있는 상세 창이 열립니다.

### 오디오 TXT 형식

문장 또는 긴 무음 구간을 기준으로 줄을 나누고, 기본으로 각 줄 앞에 `[시작 - 종료]` 타임스탬프를 넣습니다. `오디오 TXT에 타임스탬프 포함`을 끄면 시간 없는 일반 텍스트로 저장합니다. SRT와 TXT 모두 UTF-8 BOM과 Windows 줄바꿈을 써서 메모장에서 바로 열립니다.

### 용어집

`용어집 / 설정` 탭에 기술 용어·제품명·고유명사를 한 줄에 하나씩 적으면 모든 작업의 인식에 반영됩니다. 중복을 제거해 최대 50개, 합계 500자까지 적용합니다.

## 주의사항

- **서명되지 않은 개인 빌드입니다.** 처음 실행할 때 Windows SmartScreen의 "Windows의 PC 보호" 경고가 뜰 수 있고, 일부 백신이 오탐할 수 있습니다. 릴리즈 노트의 SHA-256과 받은 파일이 같은지 확인한 뒤 실행하세요.
- **인식 결과는 틀릴 수 있습니다.** 고유명사, 숫자, 겹치는 말소리, 잡음이 많은 구간은 특히 그렇습니다. 중요한 용도라면 사람이 검토하세요. `완료 / 검토 필요`로 표시된 파일은 먼저 확인하는 편이 좋습니다.
- **CPU로 우회하지 않습니다.** GPU를 쓸 수 없거나 메모리가 부족하면 조용히 느린 방식으로 바꾸지 않고 실패로 알립니다.
- **RTX 3080 12GB 한 대에서만 실측했습니다.** 그래픽 메모리가 부족하면 처리 단위를 4 → 2 → 1로 낮춰 다시 시도하지만, 그래도 부족하면 실패합니다. 다른 GPU에서의 동작과 속도는 확인하지 못했습니다.
- **재생성은 덮어쓰기입니다.** `선택 재생성`과 `선택 전체 large-v3`는 기존 SRT/TXT를 `.bak` 하나로 옮기고 새로 만듭니다. `.bak`은 하나만 유지하므로 두 번 재생성하면 처음 결과는 사라집니다.
- **EXE와 데이터 폴더는 함께 옮기세요.** EXE만 다른 곳으로 옮기면 10GB를 다시 설치합니다.
- **권리와 동의를 확인하세요.** 다른 사람의 강의·회의·통화 녹음은 저작권과 당사자 동의 범위 안에서만 사용하세요.
- 이 프로그램은 무보증으로 제공됩니다. 자세한 내용은 [LICENSE](LICENSE)를 참고하세요.

## 세부 동작

- 영상 옆에 같은 이름(또는 `이름.ko.srt`처럼 언어 코드가 붙은) SRT/VTT/ASS/SSA가 있거나, 오디오 옆에 같은 이름의 TXT가 있으면 기본 생성에서 건너뜁니다.
- 불확실한 구간이 발화 시간의 30% 이상이거나 재처리 후에도 의심스러우면 `완료 / 검토 필요`로 표시합니다. 전체 `large-v3` 인식은 자동으로 실행하지 않습니다.
- 구간 재처리가 실패해도 검증된 Turbo 결과로 저장하고 `완료 / 경고`로 표시합니다.
- 중지하면 미완성 SRT/TXT는 저장하지 않습니다. 이미 끝난 Turbo 인식 결과는 캐시에 남아 다음 실행 때 다시 씁니다.
- 처리 도중 원본 파일이 바뀌면 결과를 저장하지 않고 중단합니다.
- 타임스탬프 옵션만 바꿔 재생성할 때는 캐시가 남아 있으면 다시 인식하지 않고 TXT만 새로 만듭니다.

## 데이터 폴더와 제거

EXE와 같은 위치에 `SubtitleTextGenerator-data` 폴더를 만들고 엔진, 모델, 다운로드, 작업 캐시, 로그, 설정을 모두 그 안에 둡니다. 레지스트리는 건드리지 않으며, 실행 중에만 Windows 임시 폴더에 실행 파일을 잠시 풀었다가 종료할 때 지웁니다.

- **제거**: EXE와 `SubtitleTextGenerator-data` 폴더를 지우면 끝입니다. 만들어진 SRT/TXT는 원본 폴더에 그대로 남습니다.
- **이동**: EXE와 데이터 폴더를 함께 옮기면 다시 내려받지 않습니다.
- **고정 버전**: Faster-Whisper-XXL r245.4, `Purfview/faster-whisper-large-v3-turbo`(커밋 `09b34be…`), `Systran/faster-whisper-large-v3`(커밋 `edaa852e…`). 내려받은 파일은 크기와 SHA-256을 모두 확인한 뒤 설치합니다.

### 1.2.x 이하(LectureSubtitleBatcher)에서 올리기

1.3.0부터 프로그램 이름이 바뀌었습니다. 이전 버전을 종료한 뒤, 새 `SubtitleTextGenerator.exe`를 **기존 EXE가 있던 폴더**에 넣고 실행하세요. 옆에 있는 `LectureSubtitleBatcher-data` 폴더의 이름을 `SubtitleTextGenerator-data`로 바꿔 엔진·모델·설정·캐시를 그대로 이어 씁니다. 다시 내려받지 않습니다.

이름을 바꾼 뒤에는 이전 EXE를 지우세요. 이전 EXE를 다시 실행하면 옛 이름의 데이터 폴더를 새로 만들고 다운로드를 시작합니다.

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| `CUDA용 NVIDIA GPU 확인 실패` | NVIDIA 드라이버를 설치하고, 명령 프롬프트에서 `nvidia-smi`가 실행되는지 확인합니다. |
| `설치 공간이 부족합니다` | EXE가 있는 드라이브에 12GB 이상을 확보합니다. |
| `CUDA 인식 실패` | 행을 더블클릭해 전체 메시지를 확인합니다. 자세한 기록은 `SubtitleTextGenerator-data\logs`에 있습니다. 다른 프로그램이 그래픽 메모리를 많이 쓰고 있으면 닫고 다시 시도합니다. |
| 데이터 폴더를 만들 수 없음 | EXE를 `Program Files`가 아닌 쓰기 가능한 폴더로 옮깁니다. |
| 결과 저장 실패 | 미디어 폴더에 파일을 만들 권한이 있는지 확인합니다. 새 결과의 검증이 끝나기 전에는 기존 결과를 건드리지 않습니다. |
| 설치가 깨진 것 같음 | `용어집 / 설정` 탭의 `환경 검사 / 복구`를 누릅니다. 설치가 끝난 상태에서 누르면 전체를 다시 설치합니다. |

## 개발 및 빌드

```powershell
.\build.cmd
```

기존 `output` EXE를 `backup\<버전>`에 보관한 뒤 가상환경과 빌드 도구를 준비하고 Ruff, Pytest, PyInstaller 순으로 실행합니다. 결과물은 `output\SubtitleTextGenerator.exe`입니다. 빌드에는 Python 3.11 이상이 필요하고, 만들어진 EXE는 Python 없이 실행됩니다.

소스에서 바로 실행하면(`python run.py`) 데이터 폴더는 `%LOCALAPPDATA%\SubtitleTextGenerator`입니다. 환경 변수 `SUBTITLE_TEXT_GENERATOR_HOME`으로 다른 위치를 지정할 수 있습니다.

검증 기록은 [QA_REPORT.md](QA_REPORT.md)에 있습니다.
