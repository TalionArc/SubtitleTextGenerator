# 강의 자막·텍스트 생성기

NVIDIA GPU에서 한국어 영상의 SRT 자막과 오디오의 TXT 녹취를 로컬로 만드는 Windows 프로그램입니다. 먼저 `large-v3-turbo`로 빠르게 초안을 만들고, 신뢰도가 낮은 구간만 `large-v3`로 다시 인식해 속도와 품질을 절충합니다.

## 바로 사용하기

1. `output\LectureSubtitleBatcher.exe`를 실행합니다.
2. 첫 실행의 자동 설치가 끝날 때까지 기다립니다. 엔진과 모델 다운로드에 약 6.1GB, 설치 중 최소 12GB의 여유 공간이 필요합니다.
3. 미디어 폴더를 확인하고 `결과 없는 파일 모두 선택` 또는 원하는 파일의 체크 칸을 누릅니다.
4. `선택 생성 (Turbo → 보정)`을 누릅니다. 선택한 미디어는 GPU 한 작업씩 순서대로 처리됩니다.
5. 영상은 `영상이름.srt`, 오디오는 `오디오이름.txt`로 원본과 같은 폴더에 저장됩니다.

기본 검색 경로는 현재 Windows 사용자의 `Desktop\강의`이며 하위 폴더까지 검색합니다. 폴더 선택 버튼으로 자유롭게 바꿀 수 있습니다.

- 영상: MP4, MKV, MOV, AVI, WEBM, M4V, WMV, TS → SRT
- 오디오: M4A, MP3, WAV, FLAC, AAC, OGG, OPUS, WMA, AIF, AIFF, MKA → TXT

오디오 TXT는 문장 또는 긴 무음 구간을 기준으로 줄을 나누고, 기본적으로 각 줄 앞에 `[시작 - 종료]` 타임스탬프를 넣습니다. `오디오 TXT에 타임스탬프 포함`을 끄면 시간과 번호가 없는 일반 텍스트로 저장됩니다. 두 형식 모두 UTF-8 BOM과 Windows 줄바꿈을 사용해 메모장에서도 바로 열립니다.

## 중요한 동작

- 영상에 같은 이름 또는 언어 코드가 붙은 SRT/VTT/ASS/SSA가 있거나, 오디오에 같은 이름 또는 언어 코드가 붙은 TXT가 있으면 일반 생성에서는 건너뜁니다.
- `선택 재생성`과 `선택 전체 large-v3`는 명시적인 덮어쓰기 작업입니다. 기존 SRT/TXT는 각각 `.bak` 하나로 보관하며 이전 백업은 교체합니다.
- 1.2.0에서 만든 타임스탬프 없는 TXT도 기존 결과로 유지합니다. 시간 정보를 추가하려면 옵션을 켜고 `선택 재생성`을 사용하며, 인식 캐시가 남아 있으면 오디오를 다시 분석하지 않고 TXT만 빠르게 바꿉니다.
- 불확실 구간이 발화 시간의 30% 이상이거나 재처리 후에도 의심스러우면 `완료 / 검토 필요`로 표시합니다. 전체 large-v3는 자동 실행하지 않습니다.
- 구간 large-v3가 실패해도 검증된 Turbo 결과로 영상은 SRT, 오디오는 TXT를 저장하고 `완료 / 경고`로 표시합니다.
- GPU 메모리가 부족하면 Turbo batch를 4 → 2 → 1 순서로 재시도합니다. CPU나 다른 모델로 조용히 전환하지 않습니다.
- 중지는 현재 Faster-Whisper 프로세스 트리와 남은 대기열을 취소합니다. 미완성 SRT/TXT는 저장하지 않으며, 유효한 Turbo JSON은 다음 실행에서 재사용합니다.
- 인식은 완전히 로컬에서 수행합니다. 인터넷은 최초 엔진·모델 다운로드에만 사용합니다.

## 전역 용어집

`용어집 / 설정` 탭에서 한 줄에 하나씩 기술 용어·제품명·고유명사를 입력할 수 있습니다. 중복 제거 후 최대 50개, 총 500자까지 Faster-Whisper의 hotwords로 모든 작업에 전달됩니다.

## 자동 설치와 저장 위치

배포용 EXE는 실행 파일과 같은 위치에 `LectureSubtitleBatcher-data` 폴더를 만들고, 엔진·모델·다운로드·작업 캐시·로그·설정을 모두 그 안에 저장합니다. EXE를 D 드라이브에 놓으면 대용량 데이터도 D 드라이브에 설치됩니다. 폴더 전체를 옮길 때는 EXE와 데이터 폴더를 함께 옮기면 다시 다운로드하지 않습니다.

다음 고정 버전을 `LectureSubtitleBatcher-data`에 설치합니다.

- Faster-Whisper-XXL 공개판 r245.4
- `Purfview/faster-whisper-large-v3-turbo` 커밋 `09b34be...`
- `Systran/faster-whisper-large-v3` 커밋 `edaa852e...`

다운로드는 `.part` 파일로 재개하며, 크기와 SHA-256을 모두 확인한 뒤 원자적으로 설치합니다. 설치가 깨진 경우 `용어집 / 설정`의 `환경 검사 / 복구`를 사용합니다.

## 문제 해결

- `CUDA용 NVIDIA GPU 확인 실패`: NVIDIA 드라이버를 설치하거나 `nvidia-smi`가 정상 실행되는지 확인합니다.
- `설치 공간이 부족`: EXE가 놓인 드라이브에 최소 12GB를 확보합니다.
- `CUDA 인식 실패`: EXE 옆 `LectureSubtitleBatcher-data\logs`의 해당 작업 로그를 확인합니다. 앱은 CPU로 우회하지 않습니다.
- 데이터 폴더 생성 실패: EXE를 `Program Files` 같은 보호 폴더가 아닌 쓰기 가능한 D 드라이브 폴더로 옮깁니다.
- 폴더 쓰기 권한 오류: 미디어 폴더에 일반 파일을 만들 수 있는지 확인합니다. 기존 결과는 새 SRT/TXT 검증이 끝나기 전에는 이동하지 않습니다.

## 개발 및 빌드

Windows에서 실행 정책 설정과 관계없이 다음을 실행합니다.

```powershell
.\build.cmd
```

스크립트가 기존 `dist`와 `output` EXE를 파일 버전별 `backup\<버전>` 폴더에 보관한 뒤 Python 가상환경과 빌드 도구를 준비하고 Ruff, Pytest, PyInstaller 순으로 실행합니다. 최종 산출물은 `output\LectureSubtitleBatcher.exe`입니다. 런타임 앱은 Python 설치를 요구하지 않습니다. `backup`의 바이너리는 Git에 포함하지 않습니다.
